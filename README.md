# maximefournes.com

Personal placeholder site, served with GitHub Pages at https://maximefournes.com.

Plain static HTML/CSS, no build step. Edit `index.html` and push to `main`.

Contact form uses [Web3Forms](https://web3forms.com) with a honeypot field. Set the
`access_key` value in `index.html` to your Web3Forms key.

Preview locally: `python3 -m http.server 8765`
